  What I did
  1. The settings model reads the four variables from the environment. A bad
     value logs a warning that names the variable, and the server falls back to
     the default for it (backend/app/settings.py).

  3. The broadcaster keeps one 2-batch queue per client and drops the oldest
     batch when a queue is full. It encodes each batch once and adds sequence
     numbers. Its background task runs on the monotonic clock
     (backend/app/broadcaster.py).
