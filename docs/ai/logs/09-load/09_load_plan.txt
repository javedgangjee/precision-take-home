  CloudWatch gives one value for each minute, so a 30 s run has no value of its
  own. The CPU is a clue only, and the pass rule does not use it.

  Pause or destroy at the end

  M5 now ends the test. You set the defaults again, stop the curl clients, and
  then choose one ending.

  - make cloud-pause: This stops the data transfer and leaves the stack running,
    which costs about $1.15 a day. You run make cloud-resume before a reviewer
    uses the server.
  - make destroy: This stops every cost. You run make deploy and read the new
    admin token before a reviewer uses the server.

  A pause saves little overnight. One open client at 20,000 samples per second
  costs about $0.40 in data transfer for 12 hours, on my estimate of AWS list
  prices. The stack is the larger cost, and only a destroy stops it.

  G14 records the step, and docs/ai-changes.md has an entry for each of the two
  changes.
