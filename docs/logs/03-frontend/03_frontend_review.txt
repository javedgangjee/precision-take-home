⏺ Your fix is right. It is not clean yet, for three reasons.

  Why it works: Setting canvas.width or canvas.height wipes the canvas bitmap,
  even when the value does not change. The browser runs ResizeObserver callbacks
  after the requestAnimationFrame callbacks in the same frame, and before it
  paints. The old code wiped the canvas in layout() and only marked it dirty, so
  the browser painted a blank canvas. The redraw came one frame later. During a
  drag, this happens every frame, so the grid stayed blank. When you draw
  inside layout(), the wipe and the redraw happen before the same paint. This is
  the standard fix.

  What is not clean:

  1. A test fails. The test "calls the renderer only on a frame when store.frame
     returns true" in heat-map.spec.ts now fails. Its fake ResizeObserver calls
     layout() on observe(), and that now calls draw once before the test
     counts. The spy needs draw.mockClear() after whenStable(). No test covers
     your fix either. It needs one that runs the resize callback and checks that
     draw runs at once, without a frame.
  2. Prettier fails. Lines 88 to 90 of heat-map.ts have 8 spaces of indent, so
     npm run lint fails.
  3. The draw call is written twice. The same renderer.draw(...) line with the
     same four arguments is in the loop at line 57 and in layout() at line 89. A
     private draw() method would hold it once:

  private draw(): void {
    if (this.ctx) {
      this.renderer.draw(this.ctx, this.store.counts, this.gridDevicePx,
  this.pixelRatio);
    }
  }

     The loop would then run if (this.store.frame(now)) this.draw();, and
     layout() would end with this.draw();.

  Two smaller points do not block the change:

  - The store comment says the store is the only owner of the dirty flag. A draw
    outside the frame loop still keeps to that, because it reads the counts and
    changes no state.
  - If a batch lands in the same frame as a resize, the grid draws twice in that
    frame. That only happens while you resize, so it does not matter.

  Do you want me to make these three changes and add the logs? That means the
  draw() helper, the test fix with a new resize test, and a Prettier run.
